# NOISEFLOOR

Самостоятельный VPN на AmneziaWG с возможностью прятать выходной трафик за
вторым сервером через VLESS+REALITY.

Два сервиса, каждый разворачивается одной командой и дальше живёт сам:
генерирует ключи, поднимает интерфейс, следит за собой и делает резервные
копии.

| Сервис | Образ | Что делает |
|---|---|---|
| **Панель AmneziaWG** | `vbif666/noisefloor-amneziawg-panel` | VPN-сервер: клиенты, обфускация, графики трафика, опционально — каскад |
| **VLESS-REALITY релей** | `vbif666/noisefloor-vless-reality` | Отдельный выходной узел, за которым прячется панель |

**Развернуть с нуля: [`docs/DEPLOY.md`](docs/DEPLOY.md)** — пошагово, без
предварительных знаний про WireGuard и iptables.

---

## Зачем это

Обычный self-hosted WireGuard решает задачу «получить другой IP», но оставляет
две проблемы. Первая — трафик WireGuard узнаётся системами фильтрации по
характерному виду пакетов. Вторая — сайты видят адрес именно вашего сервера,
а он один и его легко заблокировать целиком.

AmneziaWG закрывает первую: подмешивает мусорные пакеты и подменяет заголовки,
из-за чего трафик перестаёт выглядеть как VPN. Профиль обфускации общий для
сервера и всех его клиентов — панель раздаёт его в конфигах автоматически.

Каскад закрывает вторую: весь трафик клиентов дополнительно заворачивается
через второй сервер по VLESS+REALITY, и наружу выходит уже его адрес. REALITY
маскирует это соединение под обычный визит на настоящий чужой сайт — сервер
переиспользует TLS-сертификат этого сайта, поэтому со стороны видно
неотличимое от обычного HTTPS.

---

## Как выглядит

Панель — тёмный интерфейс на две вкладки.

**Пиры** — список устройств: кто онлайн, сколько прошло трафика, когда был
последний контакт. Сверху график скорости по всему туннелю и значок каскада,
который зеленеет и пульсирует, пока через каскад реально идут данные.

**Сервер** — сеть, параметры обфускации, настройка каскада, резервные копии.

Добавление устройства — одна кнопка: панель сама генерирует ключи, выдаёт
адрес в туннеле и показывает QR-код для приложения AmneziaWG.

## Разработка

Тесты не требуют ничего, кроме Docker: юнит-тесты гоняются прямо в рабочем
образе, приёмочные поднимают сервисы на изолированных портах и не мешают уже
работающим на этой же машине.

```bash
# юнит-тесты
docker build -t panel:test amneziawg-panel
docker run --rm -v $PWD/amneziawg-panel/src:/src -v $PWD/tests/unit:/tests:ro \
    -e PYTHONPATH=/src -w /src panel:test \
    python3 -m unittest discover -s /tests -p 'test_*.py'

# приёмочные: разворачивают оба сервиса и проверяют, что трафик реально идёт
tests/smoke.sh
```

Приёмочный тест намеренно считает успехом не «сервис запустился», а
«через сервис прошли данные». Это не педантизм: обе крупные аварии проекта
выглядели как полностью здоровый сервис с нулевым трафиком, и ровно этот
тест ловит такое за минуту.

## Принципы, на которых это держится

**Версии закреплены.** Ни один компонент не обновляется сам. Раньше сервер раз
в сутки скачивал свежий тег VPN-движка, собирал его прямо в бою и передёргивал
сетевой интерфейс — то есть устраивал обрыв связи в случайное время. Теперь
обновление это `docker compose pull`, запущенный человеком.

**Здоровье измеряется трафиком, а не наличием процесса.** Панель сама делает
пробный запрос через каскад и показывает результат. Запущенный процесс, через
который не проходит ни байта, — это состояние, в котором проект однажды провёл
месяц, не заметив.

**Правила фаервола нельзя продублировать.** Они живут в отдельных цепочках,
которые очищаются перед заполнением, поэтому сколько раз ни перезапускай
контейнер, останется ровно один комплект.

**Ключи не теряются.** Резервные копии снимаются сами, с шифрованием, если
задан пароль.

## Что ещё не сделано

Честный список, чтобы не было сюрпризов:

- **Фаервол не настраивается автоматически.** Панель управления по умолчанию
  доступна из интернета и работает по обычному HTTP без шифрования. Как это
  закрыть — в [`docs/DEPLOY.md`](docs/DEPLOY.md), раздел «Что важно сделать
  после установки». Автоматизация этого — следующая задача.
- **Резервные копии лежат на том же сервере.** От случайного удаления спасают,
  от потери сервера — нет. Увозите копию сами.
- **Клиенты не изолированы друг от друга** — устройства в одном туннеле видят
  друг друга. Есть переключатель `isolate_clients`, по умолчанию выключен.
- **IPv6 доведён наполовину**: клиентам раздаётся маршрут, но выхода нет.

Подробный разбор состояния с приоритетами — в аудите проекта.
